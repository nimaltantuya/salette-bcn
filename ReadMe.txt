# Salette BCN

A responsive restaurant website for Salette, a fresh salads and poke restaurant in Gràcia, Barcelona.

## Features
- Bilingual EN/ES interface
- Menu filtering
- Glovo order link
- Google Maps location
- Dark/light theme
- Responsive layout

## Live site
https://nimaltantuya.github.io/salette-bcn/

## Tech stack
HTML, CSS, JavaScript, GitHub Pages
